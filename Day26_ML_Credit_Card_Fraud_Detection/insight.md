Day 26 — ML Credit Card Fraud Detection
Dataset: Kaggle Credit Card Fraud (284,807 transactions)
Question: Can we detect fraudulent transactions accurately?
Answer:

Only 0.17% fraud — severe class imbalance
Model accuracy 100% — misleading!
Fraud recall 72% — 28% frauds missed
Fraudsters test with small amounts ($9.25 median) before big transactions

Tool: Python — Logistic Regression
Key concept: Class Imbalance, Precision, Recall, F1 Score
