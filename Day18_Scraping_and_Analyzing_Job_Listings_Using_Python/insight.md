# Day 18 - Web Scraping & Analysis

Built a Python web scraping project using Requests, BeautifulSoup, and Pandas.

## Features
- Scraped 100 job listings
- Extracted job title, company, and location
- Stored data in a Pandas DataFrame
- Exported results to CSV
- Analyzed job title and company frequencies

## Technologies
- Python
- Requests
- BeautifulSoup
- Pandas

## Key Learning
- HTML Parsing
- Data Extraction
- Data Cleaning
- Data Analysis
- CSV Export
